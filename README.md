管理员把某个账号的写权限收回之后，这个账号仍然能改数据，半小时后才突然开始被拒：缓存条目必须按主体、受众、权限集合的完整内容与版本共同定位，权限集合参与定位时与书写顺序无关并去掉重复项，版本前进之后旧条目不再命中；权限变更必须让旧条目立即失效，同一主体在不同受众下不得共用条目，空权限与全部权限必须算作不同情形，已经过期的条目不得命中，有效期的单位换算必须正确，秒与毫秒不能混用；按主体失效要删掉该主体的全部条目，按权限失效只匹配权限完全相同的条目，批量请求逐条处理且彼此独立。不变量：同一输入重复查询结果一致；权限集合顺序打乱后仍定位到同一条目；失效之后旧条目不再返回。

数据约定：存储是一个字典，键由缓存键接口生成，值是条目字典；条目至少包含主体、受众、权限集合、版本、值、写入时间与过期时间。now 以秒计，ttl 以毫秒计。

接口约定：缓存键由主体、受众、权限集合与版本共同决定，版本前进之后旧键不再命中原有结果；读取接口以 now 判定过期，过期与版本不符一样视为未命中并返回 None；按主体或按权限失效时返回实际删除的条目数，按权限失效只应命中权限完全相同的条目；校验接口返回问题描述列表，健康存储返回空列表；批量接口为每个请求返回各自的键与查询结果，请求之间互不影响。
